# SatBackupToolkit

Консольная утилита на C# / .NET 10 для резервного копирования файлов и подготовки протоколов SAT (Site Acceptance Test) в Markdown.

Проект предназначен для работы с файлами, архивами ZIP, SHA-256, JSON и формирования технической документации. Внешние NuGet-пакеты не используются.

## Возможности

### Резервное копирование
- Создание ZIP-архива выбранной папки.
- Создание JSON-манифеста внутри архива.
- Расчёт SHA-256 для каждого файла.
- Проверка целостности архива.
- Восстановление только после успешной проверки.
- Восстановление разрешено только в пустую папку.
- Проверка путей в архиве против выхода за пределы папки восстановления.
- Символические ссылки не включаются в архив.

### SAT-протокол
- Ввод информации о проекте и испытательной площадке.
- Добавление тест-кейсов.
- Статусы: Passed, Failed, Blocked, NotRun.
- Автоматический подсчёт результатов и процента успешных тестов.
- Формирование Markdown-документа с шагами, ожидаемыми и фактическими результатами.
- Раздел итогового заключения и таблица подписей сторон.

## Требования

- .NET 10 SDK.
- Windows, macOS или Linux.

## Запуск

В терминале перейдите в папку проекта и выполните:

```bash
dotnet restore
dotnet build
dotnet run
```

## Пример работы с резервными копиями

Создать архив из примеров:

```bash
dotnet run -- backup ExampleData Backups
```

Проверить архив:

```bash
dotnet run -- verify Backups/backup_20261105_120000_000.zip
```

Восстановить архив в пустую папку:

```bash
dotnet run -- restore Backups/backup_20261105_120000_000.zip RestoredProject
```

Путь к архиву в командах выше приведён как пример. Используйте фактическое имя файла, выведенное приложением.

## Генерация SAT-протокола

Через меню выберите пункт 4 или запустите:

```bash
dotnet run -- sat
```

Утилита задаст вопросы о проекте и тест-кейсах. Готовый `.md` файл появится в папке `Protocols`.

Пример готового документа находится в `Examples/SAT-example.md`.

## Скрипты-обёртки

В папке `Scripts` находятся примеры запуска через PowerShell и Bash:

- `backup.ps1` / `backup.sh` — создание резервной копии папки `ExampleData`.
- `generate-sat.ps1` / `generate-sat.sh` — запуск интерактивной генерации SAT-протокола.

Скрипты не требуют прав администратора. Запускайте их из папки проекта либо через указанный в скрипте путь к проекту.

## Как работает SHA-256

При создании архива утилита рассчитывает SHA-256 каждого добавляемого файла и записывает значение в манифест `__sat_backup_manifest__.json`. При проверке архив читается повторно, хеши и размеры файлов сравниваются с манифестом. Если хотя бы один файл отличается, восстановление запрещается.

## Важные ограничения

- Во время создания копии желательно не изменять исходные файлы.
- Восстановление выполняется только в пустую папку, чтобы не перезаписать существующие данные.
- SAT — Site Acceptance Test. Итоговый должен быть проверен ответственными лицами.
